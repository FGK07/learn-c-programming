# Learn C Programming

A collection of C programming materials, examples, and exercises designed to help beginners learn the C programming language step by step.

## 📚 About

This repository is an open-source learning project for anyone who wants to learn C programming, starting from the basics and gradually progressing to more advanced topics.

The goal of this project is to provide simple, organized, and practical examples that make learning C easier.

## 💻 Getting Started

To clone this repository:

```bash
git clone https://github.com/USERNAME/learn-c-programming.git
```

Go to the project directory:

```bash
cd learn-c-programming
```

Compile a C program using GCC:

```bash
gcc hello.c -o hello
```

Run the program:

```bash
./hello
```
